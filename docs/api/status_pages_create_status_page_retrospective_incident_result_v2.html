Request body

application/json

Property Type Required Description
idempotency_key string Yes A unique key to de-duplicate requests. If you send a request with an idempotency_key that was already used, the original response will be returned.
name string Yes A title for the incident
status_page_id string Yes ID of the status page. You can find this by calling the ListStatusPages endpoint.
updates array of object Yes The reconstructed timeline of updates for this incident, ordered chronologically (earliest first). The final update must set incident_status to "resolved".
updates[].component_statuses array of object No An array of mappings from component ID to component status at the time this update was published
updates[].component_statuses[].component_id string Yes The ID of the affected component. This may be found by calling the ShowStatusPageStructure endpoint.
updates[].component_statuses[].component_status enum: operational, degraded_performance, partial_outage, full_outage Yes The status of the relevant component in a status page incident
updates[].incident_status enum: investigating, identified, monitoring, resolved Yes Current status for this incident
updates[].message string Yes Markdown update on what's changed about this status page incident
updates[].published_at string (date-time) Yes When this update was published. Must be in the past.
