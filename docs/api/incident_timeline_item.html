create

POST /v2/incident_timeline_items

Operation ID: Incident Timeline Items V2#Create.

Authentication: bearer token (BearerAuth).

Request body

application/json

Property Type Required Description
description string No Description of the timeline item, in markdown
idempotency_key string Yes Unique string used to de-duplicate timeline item requests. Retrying with the same key returns the item the first request created, rather than adding a second one.
incident_id string Yes Incident to add this item to
timestamp string (date-time) Yes When the thing this item describes happened. This is where the item sits on the timeline, and can be in the past.
title string Yes Title of the timeline item

application/json

Property Type Required Description
incident_timeline_item object Yes An item on an incident's curated timeline. The timeline is the narrative of an incident, as opposed to the activity log, which records everything that happened. Some of that activity - a pinned message, an escalation, an event a workflow added - is promoted onto the timeline, and those items carry the ID of the activity log entry they came from. The rest are custom, written by hand in the dashboard or through the API, and have no activity_log_id.
incident_timeline_item.activity_log_id string No ID of the activity log entry this item was promoted from. Null for items written by hand, which are the items whose timestamp can be changed.
